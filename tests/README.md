# Pruebas automáticas

La herramienta se elige en la etapa 3 (`docs/arquitectura.md`). Tiene que poder correr en
5 navegadores.

Reglas:

- **Error significa test primero**: antes de arreglar, una prueba que falla mostrando el problema.
- Esa prueba lleva la etiqueta de su observación: `@OBS-014`.
- Lo que una prueba automática puede verificar no va al guion de la entrega.
