# Espejo del artifact

Copia de los datos del artifact del proyecto, en JSON. Claude Code la actualiza al aprobar
cada etapa, al cerrar cada entrega y en cada salida a producción.

Sirve de respaldo y deja la historia en git. **No se edita a mano**: la fuente es el artifact.

```
observaciones/OBS-001.json
decisiones/DEC-01.json

salidas/prod-2026-10-15.json
marcas/E-01/items/cierre.json
```
