# Pantallas

Etapa 2. Una imagen por pantalla del funcional, con el código como nombre de archivo:

```
P01.png
P02.png
C3.png
```

El código es el mismo que usa `docs/funcional.md`.

Las imágenes se cargan de dos maneras:

- **En el artifact** (Definición → 2. Pantallas): se toca el cuadro y se pega con Ctrl+V, o
  se elige un archivo. Al aprobarse la etapa, `/etapa` las copia a esta carpeta.
- **En esta carpeta**: se guarda el PNG con el código como nombre y `/etapa` lo publica en el artifact.

El artifact muestra qué pantallas del funcional todavía no tienen imagen.
